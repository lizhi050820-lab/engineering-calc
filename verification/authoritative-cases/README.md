# 权威固定算例库

这里只收录可追溯到标准条文、正式出版教材、高校教学资料或学术期刊的固定算例。随机生成的算例不允许放在此目录。

## 证据等级

- A：国家标准原文、政府公开文件、高校官方课程资料、正式学术期刊。
- B：能识别章节和例题的教材或教学资料公开镜像，但缺少官方出版页面。
- C：普通网站、论坛或无法确认版本的资料，只能帮助发现问题，不能作为发布门禁。

`status=gate` 的算例必须通过。`status=review` 表示资料与当前程序采用的工程方法不完全一致，必须记录差异并由工程方法审查决定，不得情绪化地调容差让它“通过”。

## 运行

```powershell
pnpm run test:authoritative-cases
```

算例数据见 [cases.json](cases.json)。仓库只保存必要的输入、结果摘要和来源链接，不复制教材或标准全文。
